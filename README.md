# LLM for Systematic Review

ML methods are increasingly applied to estimate treatment effects in healthcare, but conducting a literature review in this emerging field is time-consuming. This thesis investigates the use of LLMs to assist the screening phase of a scoping review on ML methods for treatment effect estimation. Using GPT-4o-mini, we designed and refined a structured prompt based on a pilot set of 100 manually labeled papers. We conducted the screening on both titles/abstracts and full-text inputs, and performance was assessed using standard evaluation metrics. GPT-4o-mini achieved 83% accuracy for title/abstract screening, which improved to 96% relaxed accuracy when considering only critical errors. Full-text screening further improved recall, reaching 100% relaxed accuracy. When combined with well-designed prompts and human oversight, this approach offers a promising solution to reduce manual workload in literature reviews.
